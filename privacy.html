Privacy Policy – ADITEJUS Studio

Last updated: 27 October 2026

ADITEJUS Studio is a private tool used only by the owner of the ADITEJUS YouTube channel to manage that channel. It is not available to other users.

What data it accesses

  • The channel owner's own YouTube channel data via the YouTube Data API: uploading and updating the channel's own videos, thumbnails, captions and playlists.
  • The channel's own YouTube Analytics reports (read-only).

How the data is used

The data is used only to publish and manage the channel's own videos and to measure their performance. It is not sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Access tokens are stored privately and are never published. No data from other YouTube users is collected.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
